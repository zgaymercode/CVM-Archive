# CommunityVoiceManager
Community Voice Manager is a Discord.js Bot made to create temporary voice channels



### Commands
-**cvowner**:   Shows who the current owner of the channel is
<br>-**cvclaim**:   Claim the voice chat if the owner has left
<br>-**cvrename**:   allows the channel owner to rename the voice chat
<br>-**cvlock**:   Locks the channel and makes it visible and joinable by those who are invited.
<br>-**cvunlock**:   unlocks a voice chat and allows it to be seen and joined by anyone
<br>-**cvinvite**:   allows a mentioned member to see and join the channel
<br>-**cvnewcat**:   Generates a new category and a join channel for that category
<br>-**cvdebug**:   Debugs the bot's perms for the server or a channel

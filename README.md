# CommunityVoiceManager
Community Voice Manager is a Discord.js Bot made to create temporary voice channels



### Commands
-**cvowner** Shows who the current owner of the channel is<br>
-**cvclaim** Claim the voice chat if the owner has left
-**cvrename** allows the channel owner to rename the voice chat
-**cvlock** Locks the channel and makes it visible and joinable by those who are invited.
-**cvunlock** unlocks a voice chat and allows it to be seen and joined by anyone
-**cvinvite** allows a mentioned member to see and join the channel
-**cvnewcat** Generates a new category and a join channel for that category
-**cvdebug** Debugs the bot's perms for the server or a channel

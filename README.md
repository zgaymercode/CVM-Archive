# CommunityVoiceManager
Community Voice Manager is a Discord.js Bot made to create temporary voice channels



## Commands
-**cvowner**:   Shows who the current owner of the channel is
<br><br>-**cvclaim**:   Claim the voice chat if the owner has left
<br><br>-**cvrename**:   allows the channel owner to rename the voice chat
<br><br>-**cvlock**:   Locks the channel and makes it visible and joinable by those who are invited.
<br><br>-**cvunlock**:   unlocks a voice chat and allows it to be seen and joined by anyone
<br><br>-**cvinvite**:   allows a mentioned member to see and join the channel
<br><br>-**cvnewcat**:   Generates a new category and a join channel for that category
<br><br>-**cvdebug**:   Debugs the bot's perms for the server or a channel
<br><br><br><br>

## Automated Tasks
<br>
-**ChannelCleanup** : Deletes Empty channels that didn't get deleted when the last member left, and removes stale db entries<br><br>
-**CatagoryCleanup** : Deletes stale catagory entries from the database.<br><br>
